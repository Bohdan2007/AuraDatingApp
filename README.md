# Aura - Voice-First Dating App

Aura is a modern dating web application that prioritizes authentic connections through voice introductions rather than just photos. The platform is designed with a highly modular architecture, featuring real-time audio interactions, an interest-based matching system, and a unique "Blind Date" experience.

## Tech Stack

### Frontend
* **Core:** React (Vite)
* **Styling:** Tailwind CSS v4
* **Icons:** Lucide React
* **UI/UX Highlights:** Custom CSS keyframe animations (audio waveforms, floating background orbs), true glassmorphism, and a neon-dark aesthetic (`#0a0612`).

### Backend & Infrastructure (WIP)
* **API:** C# / .NET 
* **Database:** PostgreSQL (with fully asynchronous data access via async/await for high scalability)
* **Authentication & Sessions:** JWT (JSON Web Tokens) for secure stateless sessions and API authorization
* **Containerization:** Docker
* **Architecture:** RESTful API with modular service layers and non-blocking I/O operations.

### Tools & Development Environment
* Cursor / Visual Studio Code
* JetBrains Rider
* Git / GitHub

## Key Features

* **Voice-First Profiles:** 15-second audio recordings replace traditional text-heavy bios.
* **Blind Date Mode:** A high-chemistry matching feature where profile photos remain blurred. Visuals are only revealed when both users listen to each other's voice intros and swipe "I'm in".
* **Interest-Based Discovery:** Modular tag system connecting users via shared music genres, favorite movies, and hobbies.
* **Interactive Chat:** 2-column messaging interface featuring custom inline audio players for voice notes.
